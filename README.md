# homebrew-stashdrives

A Homebrew tap for [StashDrives](https://stashdrives.com).

```bash
brew tap you/stashdrives
brew install --cask stashdrives
```

Then updates are `brew upgrade`.

## What this repository contains

One file: `Casks/stashdrives.rb`, generated by `Scripts/release.sh`. It holds a
download URL and a `sha256` checksum.

**No source code.** StashDrives is not open source, and this tap is not how it
would be. A cask is a pointer to a compiled `.app`; the Swift sources live in a
private repository.

## Gatekeeper

StashDrives is not code-signed, and Homebrew sets the quarantine attribute on
cask downloads *on purpose* — it is imitating what a browser does. So a Homebrew
install is the one path that may need this once:

```bash
xattr -dr com.apple.quarantine /Applications/StashDrives.app
```

The install command on https://stashdrives.com/download does **not** need it,
because it fetches the disk image with `curl`, which does not set the attribute.
